# Monte Carlo methods 

-> There is no single Monte Carlo Method
-> any attempt to define one will inevitably leave out valid examples - but many simulations follow this pattern.
-> model a system as a (series of) probability density functions (PDFs).
-> repeatedly sample from the PDFs.
-> tally/compute the statistics of interest.

-> monte carlo simulation always involves an element of randomness, often at many points in the model.

-> Probability density functions (PDFs)
-> functions that define the range of possibilities and the relative probabiltiy of those possibilities for a given step in the simulation.
-> (non-negative real-valued function) (its integral over its range must be 1)
-> For sampling purposes we often use the cumulative distribution function (CDF), which is defined as an integral of the PDF, for the uniform distribution.
-> the CDF tells us the probability that a number sampled randomly from the PDF will be <= x. 

-> a pseudo-random number generator, (RNG), is a deterministic computer algorithm that produces a series of numbers that sharees many of the characteristics of true random samples.
